Replace your MQTT broker with NATS Server v2.2.0+ NATS Server v2.2.0+ has native support for MQTT v3.1.1 protocol. If you already have a deployment with existing MQTT broker(s) and use NATS messaging, or are planning to, this blog post will show you how easy it is to replace your existing MQTT broker with a NATS server. Not only you would have to manage a single server instead of two, using NATS with MQTT will allow you to exchange data from MQTT to NATS and vice-versa.
