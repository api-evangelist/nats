NATS Java Client Latency Benchmarking Many users have asked to see how the NATS Java client performs specifically in regard to latency. This blog will discuss using the NatsAutoBench program to run a latency test and how to generate a CSV file that can be used to make a histogram. The NatsAutoBench can run a variety of tests.
