We are thrilled to announce that NATS Server 2.12 is here! 🎉
A successful 6-month release cycle When we released the 2.11 version of the server back in March, we mentioned in our release blog that the 2.10.x series was our longest yet, having reached 26 patch releases.
With that, we have reflected on the need to be more predictable and transparent with our releases and have moved to a 6-month release cycle.
